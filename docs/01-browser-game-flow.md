# 浏览器玩法蓝图（当前版）

## 形式约束

- 序章结束后先进入周惜的电脑桌面。记事本保存普通行程清单；浏览器从搜索页开始，玩家根据清单搜索“泊岸旅行”。
- 主要体验发生在模拟浏览器内，不制作大而全的电脑桌面。
- 核心工具是地址栏搜索、浏览记录、下载记录、照片对比、网址修改和跨站信息核验。
- 不设置自动整理证据的线索簿。搜索只验证玩家已经发现的词，不主动发放下一题答案。
- 安时必须分层出现：公开活动、病友社区、基金会、个人神话和更深来源不能挤在同一个页面里。
- 关键事实至少由两份彼此独立的材料支持；网页不替玩家总结“这是账号接管”或“这是骗局”。
- 每道谜题既要产出事实，也要改变玩家对周惜、顾惟真或安时的理解。

## 玩家循环

1. 在普通网页、订单、照片或账号中发现矛盾。
2. 提取地点、名字、原句、时间或图片细节。
3. 使用浏览器搜索、改网址或回到旧页面对照。
4. 找到来自另一个网站的独立材料。
5. 回到此前的页面，重新理解同一件事。

## 已实现与已确定的调查顺序

### 序章：已经开始的旅行

- 林知还与周惜抵达雾汀，旅行前两日看似正常。
- 周惜长期喜欢林知还，又把得不到回应逐渐解释成抛弃和亏欠。病情恶化后，她在安时诱导下把林知还填为第七期关系人。
- 8月25日清晨，周惜借口买药离开后在沿海路口遭遇车祸。开场只把它当作普通事故，电脑留在民宿。

### 可并行支线：我的少女心事

- 桌面只保留“照片”，其中有一个锁定的“隐私相册”，不再把隐藏相簿单独做成桌面应用或侧栏位置。安全问题标题为“我的少女心事”，只提示“请输入三个字”，答案是“林知还”。
- 相簿按时间排列。前两张是较早的温柔记录；8月21日23:49和8月22日00:06出现两张不同的新照片，林知还的五官被反复用红色涂抹覆盖，备注为“为什么偏偏是你”“最亲近的人，才算数”。时间位于周惜回复第七期邀请之后、8月23日正式确认关系人之前。
- 相簿只证明感情如何由喜欢混入怨恨，不能证明周惜是否识破骗局，也不能证明事故是谁制造。

### 第一章：取消剩余行程

- 五笔公开预订全部位于“泊岸旅行”的“我的订单”。
- 浏览器下载内容不再保存灯塔接驳电子票；灯塔运营方凭证与核验尾号直接显示在该订单详情中。
- 记事本勾选只是个人标记；只有五笔订单真实取消，才触发安时接送通知。
- 取消顺序不受限制。错误校验、未确认退款规则、未打开电子票和只退一位乘车人都不能提前完成。
- 通知写明8月31日21:40、雾汀北站、2人，进入不属于泊岸旅行的安时接送订单。
- 接送订单无法由乘车人自行取消，预订来源把玩家带到安时公开活动网站。

### 第二章：未公开的第七期

- 安时官网只公开01—06期活动，网址形成连续编号。
- 回收站里的走廊裁剪图看不到“第七期”；山线民宿详情轮播的第三张才是同一走廊的完整图，左侧保留“第七期”指示牌。
- 玩家对比两张图后，将公开归档网址末尾改为07，进入未列出的“第七期 · 海边同行”。
- 第七期页面中的四行来信以“归、潮、见、证”开头，只加粗首字，不解释藏头。这里不出现 R-06-4 或其他内部编号，避免玩家在刚进入07页时跳进后段。
- 解锁后出现的安时论坛讨论只能说明“有一期没有列入公开归档”，不得直接写“第七期”或07；活动序号必须来自完整走廊照片。

### 第三章：死后仍在更新的账号

- 搜索“归潮见证”进入表面普通的病友与家属匿名社区。周惜的电脑已登录“潮汐失眠”，其早期记录与打码病例解释她为何接近安时。
- 玩家从社区进入第六期公开记录和账号“雨停以后”。8月19日的账号仍称会恢复更新，但8月16日的旧动态已经说自己即将住院。
- 旧动态中的“米粒”引出寻猫启事；地址“青桐里3栋”引出社区治丧通知，第一次得到真名程叙白。
- 程叙白的正式讣告证明他在8月17日已经死亡。玩家自行完成“账号在本人死后继续更新”的时间矛盾，页面不直接宣布账号被接管。

### 第四章：顾惟真的公开神话

- 归潮社区页脚进入安时基金会，公开创办人顾惟真。
- 搜索顾惟真只出现人物资料页，并从中得到口述自传《走到今天》。书房采访与《山居杂记》不再与人物资料并列出现。前六章只展示成长、创业与公益摘要；第七章才出现病危夜晚。
- 自传第一章必须把信仰写成持续三十余年的具体生活：少年时为母亲抄经、家中设佛堂、初一十五茹素、每日上香换水，创业出差也携带念珠和经本。这样才能证明顾惟真不是病危时临时求神。
- 第七章先写他在海岬病床上从熟悉了几十年的经咒和佛号开始，得不到回应后才慌乱地求向其他宗教与陌生神名；顾将这解释为“三十多年的供奉与临时喊出的陌生名字得到同一种沉默”，从而彻底失去信仰。
- 第六章写他出院后撤去佛堂、停止寺院供养，并在三个月后把大部分供奉与佛教藏品集中委托拍卖。搜索专场名“澜序旧藏·佛教艺术”进入2017年嘉闻春拍图录，看到31件全部成交，以及手抄《心经》、家中旧供观音、供养记录和香具等长期信佛的物证。
- 第七章同时提到海岬和济医院、好友陆闻川以及“我活了下来，闻川却没等到天亮”。
- 搜索陆闻川得到事故报道；搜索海岬和济医院得到顾惟真的抢救记录。两份材料共同建立安时后来反复利用的第一场“神迹”。

### 第五章：无面小像

- 玩家先从自传第六章进入后来书房采访，再由采访页进入《山居杂记》。书房照片中的无面小像不是装饰性素材，必须保持可发现；两份深层材料不得在第一次搜索顾惟真时提前出现。
- 2023年书房采访再次提到他2014年仍早晚礼佛、书房曾有三层供架，2017年春拍后供架与大部分藏品消失；只剩最早的香炉和念珠封在箱底。顾本人明确说“已经不信这些了”。这份旁证与自传第一、六、七章及春拍图录共同构成信仰断裂。
- 2018年无面小像仍保持匿名竞得，不能直接写买家是顾。玩家只会先看到顾在2017年卖掉自己供奉多年的佛教藏品，再从书房照片、秋拍记录和“先生”旧帖推断无面小像后来进入了他的空间；“卖掉有名有相的佛，留下无名无面的像”是玩家得出的对照，不是网页标题给出的答案。
- 搜索诗中的“大罗无相尊”会同时出现临川文献馆的仪轨残卷和一篇普通民间迷信帖。发帖人只说自己偶然听到这个神佛，写下名字、供了一杯清水后碰巧等到床位，愿意相信是得到了保佑。回复里仅有一句顺带提到顾惟真曾在公开文化活动中说自己听过这个名字，不出现“先生”、名单、北麓中心或旧院，也不让教徒知道该神名对应顾惟真。文献馆结果继续连接秋拍记录与旧藏网讨论串。
- 这条线用于追查顾惟真如何把偶然幸存包装成可复制、可崇拜的个人神话；当前只完成材料入口，不在页面上直接给出最终解释。

### 第五章补线：北麓路17号

- 这条线先从周惜8月20日的浏览历史“临川异地就医 陪护短住”独立出现，不能由顾惟真的诗直接带出。
- 搜索记录进入临川北麓康复中心。公开官网只呈现院外短住、康复衔接、家属喘息与资源协调，地址为北麓路17号东院；不出现安时、顾惟真、神名或内部编号。
- 临潮重症援助回顾证明中心确实协调过会诊、转运、重症床位、特殊用药与陪护住宿。公开个案全部好转，归档留言只质疑为什么没有其他结果。
- 北麓康复中心官网地址中的“东院”本身就是可追查的异常；点击“为什么地址写东院”进入地方建筑沿革。搜索“北麓路17号”也会自然出现现用机构与地址沿革两条结果，不再要求玩家拼出“栖潮旧院 北麓路17号”这种不自然的组合搜索。档案显示北麓疗养院曾增挂“栖潮疗养院”院名；2018年东院登记为康复中心，西院仍为非公开办公与档案保管处。
- 地方建筑档案的数字化移交附记直接开放援助项目工作批注；批注再开放第六期记录校对样本。编号仍作为世界内档案标识保留，但正常路线不要求玩家复制编号到搜索框。
- QC-AID-19 说明 QC 是栖潮疗养院旧档案前缀，并证明顾优先选择存在可逆因素、资源介入后可能短期改善且愿意公开回访的人；无改善或死亡个案留在内部台账但不会公开。材料同时规定官方否认神迹，却不主动纠正参与者的神化语言。页末的关联抽查样本此时才第一次给出 R-06-4。

### 第六章：不会失败的记录

- 第六期记录校对不在第七期页面出现，而是在玩家追到旧院、西院档案并读完援助工作批注后，才通过“关联抽查样本”开放。玩家直接打开已经停止公开访问的校对缓存，不需要复制编号搜索。
- 修订单并列“雨停以后”8月16日原始动态与8月19日公开更新，同时记录项目组账号 RC-03 已接手账号、死亡信息不得进入公开页面。
- 修订单引用内部规则 S-17。规则把知情者分为公开服务组、联络组、记录组与说明会成员，并明确每组由重病申请者和其自行确认的最深关系人组成。
- S-17 的附件进入2019年项目说明会纪要。顾惟真把陆闻川之死解释为自己获准说明死亡代价的资格，并规定所有结果都不能被写成失败。
- 三页分别证明“账号被接管”“关系被当作筛选条件”“最终解释权属于顾惟真”，不由一张反派说明书一次讲完。

### 第七章：骗局证据归档

- 说明会纪要末尾开放内部档案交叉检索 A-00，但不自动整理玩家看过的证据。
- 说明会后的归档台混合展示六份已读材料。玩家从中选择四份真正证明骗局运转方式的证据：选择性援助、死后账号更新、记录组续写规则、顾的最终解释权。海岬幸存与佛教藏品出售只解释人物经历，不能当作骗局证据。
- 玩家不再填写四个人名或档案号。选择正确后，系统才把四段机制并列：顾用筛选制造好转、用删改和续写藏起失败，再让任何结果都只能由他解释。
- 同一检索唯一返回第七期申请确认单 A-07-02。联络摘要显示安时8月20日经归潮社区私信接近她；周惜8月21日承认已有共同出行的朋友并要求自己决定何时告知；8月23日00:14本人填写林知还是关系人，确认对方不知道完整目的，并二次输入姓名。
- A-07-02 保留“已确认 / 未撤销”的系统状态，并直接开放事故设备恢复通讯。确认单证明周惜曾主动背叛林知还；下一阶段不再寻找“她是否完成退出”，而是追查她识破骗局后与顾发生了什么。

### 第八章：嘲讽、转发与狂热信徒

- WX-0825 显示周惜向顾指出 R-06-4 与 QC-AID-19 的造假逻辑，承认自己曾想拿林知还换命，并嘲笑顾不配被称为“大罗无相尊”。她表示天亮后将公开材料。
- 对话页显示一次已撤回的外部转发痕迹，玩家点击“追踪撤回的转发”进入接收端回执，确认顾把对话、山线民宿和05:10前往北站的路线发给“近身见证”。
- 顾不直接要求任何人行动，只说“有人正在伤害大家相信的东西”；账号“守潮人-17”回复“明白”。
- 转发回执进入归岸者旧站。更早的帖子显示信徒早已把顾称为“大罗无相尊”：顾既不承认，也不否认；信徒下跪时，他不叫他们起来。
- 事故当日删除帖留下车辆 LC·7M21 与西院出发信息，06:07又更新“已经安静了”。页面直接提供“调取同号车辆影像”，不要求再次搜索号牌。

### 第九章：最后六小时

- 交通影像只证明 LC·7M21 从北麓路17号西院驶出、尾随周惜并在碰撞后异常离场，单独不能证明顾授意。
- 玩家把五张记录卡按时间排序：周惜准备曝光、顾转发、信徒与车辆离开西院、车辆尾随碰撞、事后删帖。玩法从“复述编号”改为“重建因果顺序”。
- 时间线正确后才显示顾惟真的删除语音。独白说明他刻意不承认神化、不直接下令，只把住处与时间交给最愿意替他行动的人。
- 最终结论是顾利用自己长期培养的狂热信徒制造周惜的意外，而不是顾亲自驾车或留下明确杀人命令。

### 终章

- 玩家提交交叉证据后，事故案转为刑事调查，顾惟真与“守潮人-17”被列入调查范围。
- 警方归还手机；未发送草稿只承认周惜曾想拿林知还换命，并把是否再见的决定留给林知还。它不承担破案，也不替周惜请求原谅。
- 最后一句同时保留两件事实：林知还查明了周惜为什么曾想让自己死，也查明了是谁让周惜真的死去。
- 第一章已经取消的旅行订单不会在结尾恢复。
