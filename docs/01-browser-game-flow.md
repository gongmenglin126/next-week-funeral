# 浏览器玩法蓝图（当前版）

## 形式约束

- 序章结束后先进入周惜的电脑桌面。记事本保存普通行程清单；浏览器从搜索页开始，玩家根据清单搜索“泊岸旅行”。
- 主要体验发生在模拟浏览器内，不制作大而全的电脑桌面。
- 核心工具是地址栏搜索、浏览记录、下载记录、照片对比、网址修改和跨站信息核验。
- 不设置自动整理证据的线索簿。搜索只验证玩家已经发现的词，不主动发放下一题答案。
- 安时必须分层出现：公开活动、病友社区、基金会、个人神话和更深来源不能挤在同一个页面里。
- 关键事实至少由两份彼此独立的材料支持；网页不替玩家总结“这是账号接管”或“这是骗局”。
- 每道谜题既要产出事实，也要改变玩家对周惜、顾惟真或安时的理解。

## 玩家循环

1. 在普通网页、订单、照片或账号中发现矛盾。
2. 提取地点、名字、原句、时间或图片细节。
3. 使用浏览器搜索、改网址或回到旧页面对照。
4. 找到来自另一个网站的独立材料。
5. 回到此前的页面，重新理解同一件事。

## 已实现与已确定的调查顺序

### 序章：已经开始的旅行

- 林知还与周惜抵达雾汀，旅行前两日看似正常。
- 周惜因嫉妒与不安说了伤人的话，林知还暂时离开，冷静后又回来明确说：“我是在生气，不是不要你。”
- 第二天，周惜借口买药离开，在前往终止秘密安排的途中发生意外。电脑留在民宿。

### 第一章：取消剩余行程

- 五笔公开预订全部位于“泊岸旅行”的“我的订单”。
- 记事本勾选只是个人标记；只有五笔订单真实取消，才触发安时接送通知。
- 取消顺序不受限制。错误校验、未确认退款规则、未打开电子票和只退一位乘车人都不能提前完成。
- 通知写明8月31日21:40、雾汀北站、2人，进入不属于泊岸旅行的安时接送订单。
- 接送订单无法由乘车人自行取消，预订来源把玩家带到安时公开活动网站。

### 第二章：未公开的第七期

- 安时官网只公开01—06期活动，网址形成连续编号。
- 回收站里的走廊裁剪图看不到“第七期”；山线民宿详情轮播的第三张才是同一走廊的完整图，左侧保留“第七期”指示牌。
- 玩家对比两张图后，将公开归档网址末尾改为07，进入未列出的“第七期 · 海边同行”。
- 第七期页面中的四行来信以“归、潮、见、证”开头，只加粗首字，不解释藏头。

### 第三章：死后仍在更新的账号

- 搜索“归潮见证”进入表面普通的病友与家属匿名社区。周惜的电脑已登录“潮汐失眠”，其早期记录与打码病例解释她为何接近安时。
- 玩家从社区进入第六期公开记录和账号“雨停以后”。8月19日的账号仍称会恢复更新，但8月16日的旧动态已经说自己即将住院。
- 旧动态中的“米粒”引出寻猫启事；地址“青桐里3栋”引出社区治丧通知，第一次得到真名程叙白。
- 程叙白的正式讣告证明他在8月17日已经死亡。玩家自行完成“账号在本人死后继续更新”的时间矛盾，页面不直接宣布账号被接管。

### 第四章：顾惟真的公开神话

- 归潮社区页脚进入安时基金会，公开创办人顾惟真。
- 搜索顾惟真进入人物资料页，并得到口述自传《走到今天》。前六章只展示成长、创业与公益摘要；第七章才出现病危夜晚。
- 自传第一章的试读提到家中佛龛、清晨上香和随身念珠，证明顾惟真并非病危时临时求神；第六章则写他出院后收起佛像与香炉，不再礼佛。
- 第七章提到海岬和济医院、好友陆闻川以及“我活了下来，闻川却没等到天亮”。
- 搜索陆闻川得到事故报道；搜索海岬和济医院得到顾惟真的抢救记录。两份材料共同建立安时后来反复利用的第一场“神迹”。

### 第五章：无面小像

- 顾惟真的公开搜索结果还包括《山居杂记》和书房采访。书房照片中的无面小像不是装饰性素材，必须保持可发现。
- 2023年书房采访再次提到他2014年仍早晚礼佛，2016年后不再使用旧香炉和念珠，并由顾本人明确说“已经不信这些了”。这份旁证与自传第一、六、七章共同构成信仰断裂。
- 搜索诗中的“大罗无相尊”会同时出现临川文献馆的仪轨残卷和一篇普通民间迷信帖。发帖人只说自己偶然听到这个神佛，写下名字、供了一杯清水后碰巧等到床位，愿意相信是得到了保佑。回复里仅有一句顺带提到顾惟真曾在公开文化活动中说自己听过这个名字，不出现“先生”、名单或栖潮书院，也不让教徒知道该神名对应顾惟真。文献馆结果继续连接秋拍记录与旧藏网讨论串。
- 这条线用于追查顾惟真如何把偶然幸存包装成可复制、可崇拜的个人神话；当前只完成材料入口，不在页面上直接给出最终解释。

### 第五章补线：栖潮书院

- 《山居杂记》的作者自注写明“写于栖潮书院，2019年秋”，给出可搜索的新地点。
- 搜索栖潮书院进入公开官网。页面保持正常，只说明安时自2018年起提供场地支持，并展示临潮重症援助项目。
- 项目回顾明确书院确实协调过会诊、转运、重症床位、特殊用药与陪护住宿；公开说明把康复归因于医疗与资源，归档留言只质疑为何公开材料全部是后来好转的人，不出现神名或顾惟真。
- 页面底部材料编号 QC-AID-19 可被精确搜索，进入工作批注。批注证明顾惟真优先挑选仍有可逆因素、资源介入后可能短期改善且愿意公开回访的人；无改善或死亡个案仍接受过援助，但不会进入公开回顾。
- 批注同时规定官网不得自称神迹，却不主动纠正参与者的神化语言。顾保留最终名单确认权，并要求“不要替他们说，也不必替他们改”，形成公开否认与民间神化之间的安全距离。
- 批注可进入同批项目说明会纪要，使栖潮书院的资源选择线与无面小像、陆闻川及顾的最终说明权汇合。

### 第六章：不会失败的记录

- 第七期来信底部的编号 R-06-4 也是一条可搜索线索。搜索编号进入已经停止公开访问的记录校对缓存；搜索结果本身只显示页面标题，不提前概括内容。
- 修订单并列“雨停以后”8月16日原始动态与8月19日公开更新，同时记录项目组账号 RC-03 已接手账号、死亡信息不得进入公开页面。
- 修订单引用内部规则 S-17。规则把知情者分为公开服务组、联络组、记录组与说明会成员，并明确每组由重病申请者和其自行确认的最深关系人组成。
- S-17 的附件进入2019年项目说明会纪要。顾惟真把陆闻川之死解释为自己获准说明死亡代价的资格，并规定所有结果都不能被写成失败。
- 三页分别证明“账号被接管”“关系被当作筛选条件”“最终解释权属于顾惟真”，不由一张反派说明书一次讲完。

## 尚未完成的主线

### 周惜如何进入第七期

- 需要补齐安时如何从病友社区接近周惜、如何确认她与林知还的关系，以及周惜在哪一步正式同意把林知还带进活动。
- 证据必须保留她的主动选择，不能把全部责任推给诱导或病情。

### 顾惟真神话与周惜主线的最终汇合

- 现有材料已经建立“陆闻川死亡、顾惟真获救”的时间重合、无面小像与仪轨来源，也通过栖潮书院的救助筛选、内部规则和账号续写显示他如何制造可见的成功、垄断解释权并隐藏失败。
- 后续要把这些规则与周惜的第七期报名材料连起来，证明她接受过什么、安时如何确认林知还是她的最深关系人。
- 最终揭露仍须依靠多处材料互证，不能让说明会纪要单独承担全部结论。

### 没有完成的取消

- 表层结论仍是周惜没有在系统中完成退出。
- 深层好结局必须由意图、路线、现实行为、物证和时间共同证明她最后主动终止；未发送消息和备忘录只能解释动机，不能承担破案功能。

### 终章：归还的手机

- 玩家依靠独立证据完成最终推理后，警方归还事故调查中暂扣的手机。
- 手机备忘录给予情感答案，但不替周惜洗白，也不要求林知还原谅她。
- 第一章已经取消的旅行订单不会在结尾恢复。

## 好结局证据要求

“周惜最后决定退出”不能只靠草稿或未发送消息，因为这些只能证明她犹豫。最终至少需要四类证据闭环：

1. **意图证据**：她查过退出方法，并准备向林知还坦白。
2. **行为证据**：事故前路线偏离原定活动准备地点。
3. **物证状态**：完成仪式所必需且不可补办的物件已被她主动归还、破坏或放弃。
4. **时间证据**：这些行为发生在她最后一次确认之后。
