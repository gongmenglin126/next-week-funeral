# 浏览器玩法蓝图（初版）

## 形式约束

- 序章结束后先进入朋友的电脑桌面。记事本保存普通行程清单；浏览器从搜索页开始，玩家根据清单搜索“泊岸旅行”，打开仍保持登录的账号。
- 主要体验发生在一个模拟浏览器内，不制作大而全的电脑桌面。
- 核心工具：地址栏搜索、反向搜图、地图、浏览记录、页面存档、网址修改、版本对比、匿名账号识别。
- 不设置自动整理证据的线索簿。玩家通过标签页、历史记录、下载与自己的笔记建立关系。
- 宗教不能通过一个入口直接公开全部设定，而要分层出现。
- 不要求唯一精确关键词；关键页面至少提供两条可行检索路径。
- 每道谜题必须同时产出一个事实结论和一次关系重读。
- 重要线索必须分散在普通网页、未关闭标签页、浏览历史、下载记录、缓存和桌面文件中；不能依赖搜索框逐题发答案。

## 玩家循环

1. 在普通网页中发现矛盾。
2. 提取地点、原句、时间或图片。
3. 使用浏览器功能检索或对比。
4. 找到新网页、旧版本或匿名身份。
5. 回到之前打开的网页重新理解同一件事。

## 章节结构

### 序章：已经开始的旅行

- 玩家与朋友抵达雾汀，旅行前两日看似正常。
- 朋友因嫉妒与不安说了伤人的话，玩家受到伤害后暂时沉默离开。
- 她把沉默理解成厌恶，以为这段关系已经结束。
- 玩家冷静后重新回来，明确说“我是在生气，不是不要你”。两人第一次把不同的冲突处理方式说清楚。
- 这次没有纵容、也没有抛弃的和解，成为她最终决定停止仪式的原因。
- 次日朋友借口买药离开，途中发生意外。电脑留在民宿。

### 第一章：取消剩余行程

- 五笔公开预订全部放在同一个“泊岸旅行”平台的“我的订单”，不制作五套换皮网站。
- 网站使用正常旅行产品界面：订单分类、状态筛选、名称/订单号检索、照片、金额、详情与退款回执。首页、订单帮助与登录账号信息可查看。
- 记事本的勾选由玩家手动操作，只是个人标记；不能用勾选状态判定退款完成。

| 订单 | 取消操作 | 普通信息中的线索 |
| --- | --- | --- |
| 南岸民宿 | 打开详情，直接确认全额退款 | 两位入住人，作为正常参照 |
| 南岸灯塔接驳 | 查阅下载中的电子票，填写核验尾号7642 | 8月18日下单；共同计划8月21日才确定 |
| 山线民宿 | 展开退款规则并确认已阅读 | 可展开一条第一入住人修改记录 |
| 旧盐场手作体验 | 打开电子票，再取消预约 | 预约附件IMG_4818.jpg，可与相册文件编号对照 |
| 回程高铁 | 选择要退票的乘车人，可分两次取消 | 两张票独立处理；只退一张不算结束这笔行程 |

- 不限定取消顺序。输入错误、未确认规则、未打开电子票、未选乘车人均不改变真实订单状态。
- 浏览器切换标签、查阅下载、打开记事本或最小化窗口时，订单进度和填写内容保留。本版为单次会话原型，真实浏览器刷新后重置。
- 最后一笔真实订单取消成功时，立即在当前界面上方弹出一次“安时接送”通知；不转场、不调暗屏幕、不改变时间，不要求先回到桌面。
- 通知写明“8月31日21:40，雾汀北站，2人”。这是一笔后续日期的夜间行程，而非22分钟后即将上车。
- 通知关闭后，可从桌面顶栏通知中心重新打开。
- 通知进入独立接送平台的WT-0831-2140订单，不出现在泊岸旅行的五笔订单中。目的地由机构安排，线上取消会返回“机构预约，乘车人无法自行取消”。
- 全部取消前不提供这笔接送的旧“处理行程”入口，也不能直接输入网址越过门槛。
- 先前的宗教快照与活动下载保留为后续调查原型，但不在第一章入口集中暴露。完整搜图、存档推理与结局尚未接成流程。

### 第二章：被删除的搜索

- 通过地址栏自动补全恢复她清除过的搜索词。
- 从疾病恐惧的普通问题逐渐进入“死期能否由他人承担”。
- 识别朋友在病友论坛使用的匿名账号。

### 第三章：缺失的第六期

- 发现生命关怀网站活动编号缺页。
- 修改 URL 并进入网页历史存档。
- 将七项旅行安排与七个生前告别流程图标匹配，证明整趟旅行都是仪式准备。

### 第四章：守夜人

- 比较两版电子讣告，发现朋友的名字被移除，玩家的身份被登记。
- 从完整聊天和被裁剪的匿名帖子中还原她对玩家的爱、自卑与误读。
- 查明宗教如何把“她会为你哭”包装为替死的自愿证明。

### 第五章：四十七分钟

- 风险页日志显示她停留 47 分 12 秒。
- 取消邮件、重新确认、账号切换和活动进度互相矛盾。
- 玩家确认她曾跨过最坏的一步：正式同意由玩家承担风险。

### 第六章：没有完成的取消

- 表层结论：她没有取消，事故救了玩家。
- 深层好结局需要额外推理：她最后离开原定路线并非去领取仪式用品，而是去归还或销毁完成仪式所必需且不可补办的凭证。
- 她没有来得及在系统中点击取消，但已经通过现实行动使仪式无法继续。

### 终章：归还的手机

- 玩家已经依靠独立证据证明她最后决定取消。
- 警方归还事故调查中暂扣的手机。
- 玩家在备忘录中读到她未完成的解释与道歉。
- 备忘录给予情感答案，但不承担破案功能。

## 好结局证据要求

“她最后决定取消”不能只靠草稿或未发送消息，因为这些只能证明她犹豫。

必须形成四类证据闭环：

1. **意图证据**：她查询取消方法并准备向玩家坦白。
2. **行为证据**：事故前路线偏离仪式准备地点。
3. **物证状态**：关键凭证已被她主动破坏或退回。
4. **时间证据**：上述行为发生在最后一次确认之后。

玩家必须同时找齐四类证据，才能推翻系统显示的“尚未撤销”。
