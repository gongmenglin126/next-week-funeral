# 终章备忘录（当前草稿）

> 人物对应：周惜写给林知还。此稿在玩家完成最终推理、警方归还手机后出现。它不是遗书，也不是为自己预知死亡而写，而是周惜决定退出安时安排后，准备回来向林知还坦白的草稿。因此它可以没有标题、没有收尾，甚至停在一句没有写完的话上。

---

一滴泪的重量，取决于落在谁身上。

他们跟我说，你会为我哭，所以你是最合适的那个人。

我听见这句话的时候，第一个感觉居然不是害怕，是高兴。我终于有一件事可以证明，你是真的在乎我。写到这里很难看，我知道。

我从小没有父母，也没有真正的家。我会考试，会把自己的东西收得很好，却不会和别人相处，不会开口要，也不相信别人给我的东西可以不用还。

是你教我，坐错车可以下一站再坐回来，菜做坏了可以倒掉，别人没有马上回消息，不一定是讨厌我。你教我的可能都是很普通的事，可那是我第一次觉得，原来我也可以不是一个麻烦。

后来我喜欢你。

现在我也不知道那是不是我以为的爱情。也许我只是第一次被一个人认真地喜欢，就把所有舍不得都叫成了爱情。也许友情本来就是爱情的一部分，只是我太想要一个只属于我的名字。

你说我们会做一辈子的朋友，我听见的却是，你永远不会爱我。你有了别人，我觉得你在离开我。你偶尔没有看见我的情绪，我就认定你其实从来没有看见过我。

我没有告诉你我想要什么，却在心里怪你没有给我。

生病以后，这些念头像烂掉的东西一样全翻了出来。我一会儿觉得自己很可怜，一会儿又觉得你欠我。我甚至想过，你还有那么多年，分一点给我又能怎么样。

昨天晚上，我又说了很难听的话。

你出去以后，我以为你不会再回来了。我甚至觉得这正好证明了他们说的都是真的：你只是习惯我在身边，从来没有真正选择过我。

后来你回来了。你说你还在生气，但生气不等于讨厌，暂时不说话也不等于不要我。

我那时才发现，也许过去有很多次，你都没有离开。只是我太害怕了，先替你决定了沉默是什么意思。

我也一直在给你的每一次好标价。

我把自己没有说出口的喜欢，算成你欠我的东西。可你从来没有这样对我。

我要先去停掉一件事。等我回来，我会全部告诉你。你可以生气，也可以不再见我。这次我不替你决定。

如果你还愿意听我说完的话，我想告诉你——

## 后续修改方向

- 保留她的不完美，不写成突然完成心理学自救的完美人物。
- 加入一两处只有两人知道的大学生活细节，减少通用告白感。
- 最后一行保持未完成，与事故发生时间相连。
- 最终版本需结合正式人物名、成长背景和玩家在序章中的具体行为再改。
