# 《下周的葬礼》核心设定（初版）

## 一句话

玩家与大学时期认识的好友已经开始了一场约定多年的旅行。旅途中，她因嫉妒与不安说了伤人的话；玩家受到伤害后暂时沉默离开，冷静后又回来明确告诉她：“我是在生气，不是不要你。”第二天，她借口外出买药，却在前往终止秘密仪式的路上意外去世。她的电脑留在民宿，玩家从取消剩余旅行订单开始，逐渐发现她曾因极端死亡恐惧，打算让玩家承担自己的死期；但更深的证据表明，前一晚的谈话纠正了她长期以来对玩家的误读，她已决定停止。

## 核心命题

她确信玩家会为自己真心悲伤，宗教便把这份确定性利用成仪式条件。真正的问题不是她是否爱玩家，而是她能否在求生欲最强烈时，停止利用这份爱。

“一滴泪的重量，取决于落在谁身上”不是教义、宣传语或仪式原文。它只由她本人写在终章手机备忘录里，是她回头以后对自己行为的理解，并在拿回手机前绝不完整出现。

## 人物核心

- 玩家与她在大学相识，玩家一直将她视为亲密好友。
- 她自卑、敏感，习惯从模糊的言行中先看见拒绝。
- 她是同性恋，并对玩家存在长期、未能说出口的感情。
- 性取向不是黑暗原因；真正推动她的是死亡恐惧、自我否定、长期压抑的嫉妒，以及宗教对这些情绪的利用。
- 她曾真实地准备牺牲玩家，也曾反复取消、重新确认。
- 她最终决定停止仪式。这个决定不能通过一句遗书宣布，必须由玩家完成最后推理才能证明。

## 两人的冲突方式

- 她对关系中的细微变化高度敏感，发生冲突后需要立即得到确认。
- 玩家受到伤害时倾向先沉默、拉开距离、处理情绪，再回来谈清楚。
- 她长期把玩家的暂时沉默理解成厌恶，把正常边界理解成抛弃。
- 旅行中的争执不是第一次出现，却是玩家第一次把这层差异明确说开。
- 触动她的不是玩家牺牲了什么，而是玩家在生气时仍然选择回来，并把“行为让我受伤”和“我不要你”清楚地区分开。

## 宗教与仪式

公开层是“死亡教育 / 生前告别体验”，为重病患者提供模拟葬礼、遗书书写、告别仪式等服务。

秘密仪式暂称“借丧礼”：求生者提前为自己举行葬礼，由与其存在强烈情感关系的人守夜。宗教以“关系确认”“承受人”“生期转移”等冷硬术语描述流程，声称求生者的原定死期会转移给对方。

玩家在仪式中的角色称“守夜人”。

这套宗教大概率没有任何超自然力量。恐怖来自朋友相信它可能有效，并一度愿意让玩家承担后果。

## 好结局

好结局不能抹掉背叛：

- 她点击过风险确认；
- 她完成过大部分准备；
- 她确实知道玩家可能承担自己的死期；
- 她最终也确实决定取消。

事故发生在她完成线上取消之前。因此系统表面仍显示“尚未撤销”，只有更深层的浏览记录、路线、线下行为和一项不可伪造的证据能够证明她最后的选择。

玩家可以不原谅她，但能够确认：她没有把最坏的自己当作最后答案。

玩家完成全部推理后，警方归还事故调查中暂扣的手机。手机备忘录里有一段事故前写下、没有来得及发送的文字。它不能代替证据证明她去取消仪式，只在真相已经成立后，解释她为什么终于回头。

## 结尾画面

剩余行程的最后一天，旅行网站询问：

> 共同出行人已无法出行。是否保留剩余一人的行程？

玩家选择继续。删除仪式预约，保留共同相册。
