# 《下周的葬礼》核心设定（当前版）

## 一句话

林知还与大学好友周惜已经开始了一场约定多年的旅行。周惜因病情恶化和强烈的死亡恐惧，被安时生命关怀基金会背后的教团诱导，相信顾惟真能够让死亡改选代价。她一度把与自己关系最深的林知还带进第七期活动，后来因两人的一次争执与和解决定退出，却在前往终止仪式的途中意外去世。她的电脑留在民宿，林知还从取消剩余旅行订单开始，逐步查出周惜曾经的选择、最后的反悔，以及安时用死者账号维持的虚假神迹。

## 核心命题

周惜确信林知还会为自己真心悲伤，安时便把这份确定性利用成控制工具。真正的问题不是她是否爱林知还，而是她能否在求生欲最强烈时，停止利用这份爱。

“一滴泪的重量，取决于落在谁身上”不是教义、宣传语或仪式原文。它只由周惜本人写在终章手机备忘录里，是她回头以后对自己行为的理解，并在拿回手机前绝不完整出现。

## 人物核心

- 玩家是林知还（“还”读 huán），朋友是周惜；两人在大学相识。
- 周惜自卑、敏感，习惯从模糊的言行中先看见拒绝。她喜欢林知还，但性取向和感情本身都不是她作恶的原因。
- 真正推动她的是死亡恐惧、自我否定、长期压抑的嫉妒，以及安时对这些情绪的利用。
- 她曾真实地选择把林知还带进仪式，也曾真实地决定退出。后一个决定不能抹掉前一个决定。
- 林知还可以不原谅她；好结局只负责证明她最后没有把最坏的自己当作答案。

## 两人的冲突方式

- 周惜对关系中的细微变化高度敏感，发生冲突后需要立即得到确认。
- 林知还受到伤害时倾向先沉默、拉开距离、处理情绪，再回来谈清楚。
- 周惜长期把暂时沉默理解成厌恶，把正常边界理解成抛弃。
- 旅行中的争执不是第一次出现，却是林知还第一次明确告诉她：“我是在生气，不是不要你。”
- 触动周惜的不是林知还牺牲了什么，而是林知还在生气时仍然选择回来，并把“行为让我受伤”和“我不要你”清楚地区分开。

## 安时与顾惟真

安时的公开层是生命关怀基金会、病友互助社区和线下告别活动，为重病患者与照护者提供交流、书写和陪伴项目。这层外壳必须足够正常，玩家不能第一次进入官网就看到完整教义。

创办人顾惟真从少年时起长期信佛：为病中的母亲抄经，家中设专门佛堂，每月初一十五茹素，清晨上香、晚间换水，创业和出差期间也随身携带念珠与折叠经本。这不是偶尔求心安，而是持续三十余年的生活秩序。海岬病危时，他先念自己熟悉了几十年的经咒与佛号；迟迟得不到回应后，才绝望地把记得的祷词和陌生神名全部喊过，却始终只得到沉默。出院后他撤去佛堂、停止寺院供养，并在2017年嘉闻春拍集中卖出历年供奉与收藏的31件佛教藏品，只把最早的香炉和随身念珠封存在箱底。他不再相信任何宗教。好友陆闻川赶往医院途中意外去世，顾惟真本人却在抢救后活了下来。他没有接受这只是医学、资源与概率共同造成的偶然结果，而是把两件同时发生的事解释为：自己被死亡放过，并拥有让死亡选择代价的资格。

顾惟真创办安时，不是为了严谨研究死亡能否转移，也不是单纯骗钱。他要更多人的生死不断证明自己的启示正确、仪式有效、本人值得追随。钱只用于维持组织；真正的欲望是崇拜、控制和永远正确。

失去原有信仰后，顾惟真通过安时介入临川北麓康复中心的援助项目。中心位于北麓路17号东院，前身院落曾名栖潮疗养院，当地称“栖潮旧院”；同址西院后来作为安时的非公开办公与材料保管处。中心提供的会诊、转运、重症床位、药费和照护支持都真实存在，多数员工也只知道正常公益工作。顾却在内层亲自挑选更可能在资源介入后好转、且愿意公开回访的个案，再让没有改善或死亡的受助者退出公开叙事。安时和中心从不正式宣称顾是神，公开页面也不出现他的名字或“大罗无相尊显应”等说法，但内部规定不主动纠正参与者的神化称呼。他借真实救助、稀缺资源与选择性公开，逐渐塑造出只让外界看见“被他选中便能活下来”的个人神话。

安时会挑选绝症者和与其关系最深的人共同参加活动，把恐惧、希望和亲密关系都交给顾惟真的解释。失败者不会被记为失败：组织接管死者账号、隐藏死亡信息，再把现实重新包装成“有人活了下来”的见证。这样做不是修改实验数据，而是拒绝让现实证明顾惟真错误。

并非所有成员都知道全部真相。外围信徒可能真心相信顾惟真救过人；负责账号和宣传的人知道材料经过修改，却把造假理解为维护信仰；只有最内层知道所谓成功案例经不起核验。

现阶段不再使用“借丧礼”“守夜人”“承受人”“生期转移”等成套教团黑话。周惜与林知还是第七期活动中被选中的一对参与者，具体仪式规则继续通过碎片证据逐步揭露，不能由设定页或官网一次讲完。

## 顾惟真的公开神话与反证

- 基金会只公开顾惟真的公益身份和重病康复经历。
- 人物资料页引出其口述自传《走到今天》；必须进入第七章，才读到病危夜晚和陆闻川之死。
- 搜索陆闻川与海岬和济医院，分别得到事故时间和顾惟真的抢救记录。此阶段只建立“好友死、顾惟真活”的公开神话，不由网页替玩家判断原因。
- 2017年“澜序旧藏·佛教艺术”成交图录证明顾在病后处置了长期供奉的旧藏；2018年无面小像、《山居杂记》、文献展、秋拍记录和旧藏网讨论串组成更深一层的来源调查，必须保持可达。叙事上的关键对照是：他先卖掉有明确名相、被自己供奉多年的佛教藏品，随后又把无名无面的像带进自己的私人体系；页面不能直接替玩家宣布2018年匿名竞得人就是顾。

## 周惜的背叛与好结局

好结局不能抹掉背叛：

- 周惜知道林知还可能承担后果；
- 她完成过大部分准备，也跨过关键确认；
- 她最终决定退出，但事故发生在她完成线上取消之前；
- 系统仍显示“尚未撤销”，只能由独立的路线、时间、现实行为和物证推翻。

警方在最终推理完成后归还周惜的手机。备忘录解释她为什么回头，但不能代替证据证明她去终止仪式。

## 结尾约束

- 第一章中的五笔旅行订单已经真实取消，结尾不能把它们悄悄恢复。
- 当前只保留一个结局方向：林知还查明真相。程叙白账号、顾惟真神话和无面小像等支线可以被错过，但不单独制造分支结局。
- 终章的具体交互仍待设计；任何新结尾都必须保留周惜曾经的选择、最后的反悔，以及林知还是否原谅她的开放性。
