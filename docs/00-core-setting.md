# 《下周的葬礼》核心设定（当前版）

## 一句话

林知还与大学好友周惜来到雾汀旅行。身患绝症的周惜长期爱慕林知还，又把得不到回应理解成抛弃，最终在安时的诱导下确认用林知还作为“关系最深的人”参加第七期。她后来查出顾惟真的神迹全靠筛选、删改和死者账号续写维持，便向顾本人发送嘲讽并威胁公开证据。顾没有直接下令，只把她的消息、住处和出发时间转给把自己视为神的狂热信徒。信徒制造交通意外杀死周惜，顾继续以“我没有要求任何人做什么”维持无罪姿态。

## 周惜与林知还

- 玩家是林知还（“还”读 huán），朋友是周惜；两人在大学相识。
- 周惜真心喜欢林知还。隐私相册早期照片是长期、温柔的私人注视，不靠日记或聊天记录解释。
- 她自卑、敏感，习惯把林知还的沉默、边界和其他关系理解成自己再次被放弃。喜欢逐渐混入嫉妒、怨恨和“你欠我”的计算。
- 病情恶化后，她把林知还仍然拥有的未来视为不公平，并真正确认过让林知还承担第七期后果。隐私相册最后两张编辑副本把林知还的脸划掉，是“由爱生恨”的视觉证据。
- 周惜发现顾惟真是骗子后反击，是因为被骗、受辱且不愿继续受他控制，不等于她已经完成道德悔悟。她识破骗局不能抹掉她曾经想用林知还换命。
- 结局不强迫林知还原谅周惜，也不把周惜写成突然完美的受害者。

## 顾惟真的形成

顾惟真从少年时起虔诚信佛三十余年：为病中的母亲抄经，家中设佛堂，初一十五茹素，每日上香换水，创业出差仍携带念珠和经本。海岬病危时，他先念最熟悉的经咒与佛号；没有得到回应后，才慌乱地向其他宗教和陌生神名求告。最终只有沉默。

出院后，他撤佛堂、停寺院供养，在2017年集中卖出长期供奉和收藏的佛教旧藏。好友陆闻川赶往医院途中死亡，顾却在抢救后活了下来。他不愿接受医学、资源和概率共同造成的偶然结果，转而相信自己获得了“解释死亡代价”的资格。

顾创办安时不是单纯骗钱。他真正需要的是崇拜、控制和永远正确：援助项目真实存在，但他只公开更可能被救回的人；失败和死亡个案被隐藏，死者账号由记录组继续更新。因此外界只会看见“被顾选中的人都活了下来”。

## 从“先生”到“大罗无相尊”

- 早期民间帖子只把“大罗无相尊”当作偶然听来的神佛名，不直接知道它与顾惟真有关。
- 更深的信徒旧站逐渐出现“先生就是尊”的说法。有人当面问顾，他不承认，也不否认，只说名称不重要、应记住是谁让他们相信自己能活。
- 信徒下跪时，顾不要求他们跪，也不叫他们起来。他让神化语言由信徒主动说出，自己只负责保留这种解释。
- 这种默许不是消极沉默，而是顾精心经营的责任隔离：他不留下“我是神”或“去杀人”的直接命令，却持续提供能让信徒替他完成下一句话的信息。

## 北麓、栖潮与成功案例

北麓康复中心位于北麓路17号东院，前身院落曾增挂“栖潮疗养院”院名，当地称“栖潮旧院”；西院后来成为安时的非公开办公与材料保管处。中心提供的会诊、转运、药费和陪护支持真实存在，多数员工只知道正常公益项目。

QC-AID-19、R-06-4、S-17与说明会纪要共同证明：顾优先挑选有可逆因素、资源介入后更可能短期改善且愿意公开回访的人；失败者不进入公开叙事；死者账号可以由项目组接手；所有结果的最终解释权归顾本人。

## 周惜之死

1. 周惜在8月23日00:14完成第七期确认，把林知还填为关系人，并承认林不知情。
2. 她随后取得 R-06-4、QC-AID-19 等材料，确认顾的神迹是被选择和维护出来的。
3. 8月25日00:18起，她向顾发送嘲讽，承认自己曾想拿林知还换命，并表示天亮后将公开证据。
4. 顾于00:31把对话截图、山线民宿和05:10前往北站的路线转发至“近身见证”群。他不直接下令，只说有人在伤害大家相信的东西。
5. “守潮人-17”回复“明白”，随后从北麓路17号西院驾驶 LC·7M21 离开。车辆在事故前持续尾随周惜；事故后该账号发布“已经安静了”并删帖。
6. 顾的晚期独白证明他的主观方式：不承认自己是神，不亲自发出命令，只把信息交给最愿意替他行动的人。

## 结尾约束

- 只有一个结局：林知还完成两次交叉核验，证明顾的神迹是人为制造，也证明周惜的死亡是顾借信徒制造的意外。
- 周惜同时是加害意图的实施者和谋杀案受害者，这两种身份不能互相抵消。
- 终章手机草稿只补充周惜的自我认识，不承担破案功能，不使用一封突然出现的遗书洗白。
- 第一章已经取消的五笔旅行订单不会在结尾恢复。
